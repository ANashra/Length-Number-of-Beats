## Overview
This repository contains the R analysis code and datasets used to investigate the role of rhythmic cycle length in rhythm perception.

> If you use this repository in any form, please cite this paper: Ahmad, N., Clayton, M., & Eerola, T. (2025). The Effect of Rhythm Cycle Length, Cultural Familiarity, and Musicianship on Learning and Recall of North Indian Rhythmic Patterns. Auditory Perception & Cognition, 1–14. https://doi.org/10.1080/25742442.2025.2586999

---

## Stimuli
The `Stimuli` folder includes all rhythmic cycle audio files used in the study. It contains: *Reference* and *Altered* versions for each of the four rhythmic cycles.
The `TutorialVideos` folder contains instructional videos for **Kehervatal** and **Jhaptal**, used in the Explicit Short-Term Learning Block of the experiment.

---

## Datasets
- `Indiandata_outlierremoved.csv` – Dataset from a previous study with Indian participants (outliers removed).
- `Westerndata_outlierremoved.csv` – Dataset from a previous study with Western participants (outliers removed).
- `PreprocessedData.csv` – New dataset collected specifically for the current study.
