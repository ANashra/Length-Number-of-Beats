Overview
This repository contains the R analysis code and datasets used to investigate the role of rhythmic cycle length in rhythm perception.
The paper to be cited will be provided after the peer review process is complete

Stimuli
The Stimuli folder contains all the rhythmic cycles used in the study. The reference and the altered for the four rhythmic cycles. The 'TutorialVideos' contains the videos for Kehervatal and Jhaptal used in the Explicit Short-Term Learning Block of the experiment.

Datasets
Indiandata_outlierremoved.csv: Dataset from a previous study involving Indian participants, with outliers removed.

Westerndata_outlierremoved.csv: Dataset from a previous study involving Western participants, with outliers removed.

PreprocessedData.csv: New dataset collected specifically for the current study.

Usage
All analysis was conducted using R. The provided scripts (Analysis and Visualisation.md) allow you to view the code for the analysis of the study.
